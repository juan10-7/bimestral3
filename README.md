# Planteamiento del Problema: Santana Legal

## Situación actual

Muchas personas tienen dificultades para encontrar información sobre servicios jurídicos, conocer sus costos, contactar a un abogado y agendar citas sin desplazarse.

Por otra parte, los abogados independientes necesitan herramientas digitales para promocionar sus servicios, organizar clientes y gestionar citas de manera eficiente.

## Causas

- Falta de información jurídica accesible.
- Dificultad para contactar abogados.
- Agendamiento de citas de forma manual.
- Poca presencia digital.
- Información de clientes dispersa.

## Consecuencias

- Pérdida de tiempo para los clientes.
- Comunicación lenta.
- Confusiones al agendar citas.
- Pérdida de posibles clientes.
- Dificultad para organizar la información.

## Solución propuesta

Se desarrollará un **sitio web para Santana Legal**, conectado a una base de datos, que permitirá:

### Clientes
- Registrarse e iniciar sesión.
- Consultar servicios jurídicos.
- Solicitar asesorías.
- Agendar citas.
- Consultar sus solicitudes.

### Abogado
- Administrar clientes.
- Gestionar servicios y citas.
- Consultar solicitudes.
- Mantener la información organizada.
- Utilizar un panel administrativo privado.

## Objetivo

Facilitar el acceso a servicios jurídicos y mejorar la gestión de clientes, citas y solicitudes mediante una plataforma web.
## Épica 1:
## HU01 - Registro de usuario

| Campo | Información |
|---|---|
| **Código** | HU01 |
| **Nombre** | Registro de usuario |
| **Quién** | Visitante |
| **Qué** | Registrarse en el sitio web |
